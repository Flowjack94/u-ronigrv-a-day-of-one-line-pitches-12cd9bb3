## The entry

One sentence, written by `main.py` to `/output/entry.txt`:

> Just describe the app idea you've been carrying around and let an AI agent on make.fun build the first version — no code from you, no jargon to learn, and you only keep it if you love it.

## How it works

`main.py` (Python 3.13, standard library only) writes the sentence above —
a fixed, deterministic string — to `/output/entry.txt`, creating the
output directory if needed. Running it twice produces byte-identical output.
